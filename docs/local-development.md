# Local Development

## Prerequisites

- Node.js 20+
- npm 10+
- PostgreSQL 15+
- Expo CLI

## Setup

1. Copy .env.example to .env.
2. Update DATABASE_URL and other secrets.
3. Install dependencies: npm install.
4. Create the database in PostgreSQL.
5. Run: npm run db:generate
6. Run: npm run db:push
7. Start backend and apps.

## Notes

The initial Phase 1 foundation is intentionally not production-complete, but the architecture is ready for the full roadmap.
